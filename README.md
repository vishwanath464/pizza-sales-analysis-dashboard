# 🍕 Pizza Sales Analysis Dashboard

## Project Overview

This project presents an interactive Pizza Sales Analysis Dashboard designed to analyze pizza sales performance, orders, revenue, customer demand, and sales trends.

The dashboard provides a comprehensive view of business performance through key performance indicators, charts, and interactive filters.

## Dashboard Preview

![Pizza Sales Dashboard](image)

## Key Performance Indicators

The dashboard provides the following KPIs:

- Total Orders
- Total Pizzas Sold
- Average Order Value
- Total Revenue
- Average Pizza Price

## Analysis Performed

### 1. Sales by Day

Analyzed the number of orders received on each day of the week to identify the busiest days.

### 2. Monthly Sales Analysis

Analyzed monthly order trends to understand changes in sales throughout the year.

### 3. Revenue by Pizza Category

Compared revenue generated by different pizza categories:

- Classic
- Supreme
- Chicken
- Veggie

### 4. Revenue by Pizza Size

Analyzed revenue contribution from different pizza sizes:

- Large
- Medium
- Regular
- Extra Large
- Extra Extra Large

### 5. Pizza Category Sales

Compared the total number of pizzas sold across different categories.

### 6. Best/Worst Seller Analysis

Analyzed pizza sales performance to identify the best-selling and lowest-selling pizzas.

## Business Questions

This dashboard helps answer questions such as:

- How many total orders were placed?
- How many pizzas were sold?
- What is the total revenue?
- What is the average order value?
- Which day has the highest number of orders?
- Which month has the highest sales?
- Which pizza category generates the most revenue?
- Which pizza size contributes the most revenue?
- Which pizza category has the highest number of pizzas sold?
- Which pizzas are the best and worst sellers?

## Key Insights

Based on the dashboard:

- Friday has the highest number of orders among the days shown.
- July has the highest monthly order volume.
- Classic pizzas contribute the highest share of revenue among the categories.
- Large pizzas contribute the highest share of revenue among pizza sizes.
- The dashboard provides a clear comparison of sales performance across pizza categories.
